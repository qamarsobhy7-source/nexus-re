# Contributing to NEXUS-RE

First off, thank you for considering contributing to NEXUS-RE! It's people like you that make NEXUS-RE such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](https://github.com/qamarsobhy7-source/nexus-re/issues) page to see if someone else has already created a ticket. If not, go ahead and make one!

## Setting up your environment

1. Fork the repository.
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/nexus-re.git`
3. Run `python doctor.py` to check your environment.
4. Create a new branch: `git checkout -b my-branch-name`

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface.
3. Increase the version numbers in any examples files and the README.md to the new version that this Pull Request would represent.
4. You may merge the Pull Request in once you have the sign-off of two other developers, or if you do not have permission to do that, you may request the second reviewer to merge it for you.
