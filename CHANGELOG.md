# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.0] - 2026-10-17
### Added
- 10 new analysis tools (Total: 31 tools).
- Professional Web Dashboard with Tailwind CSS and Prism.js.
- Live Demo deployed on Hugging Face Spaces.
- Comprehensive Technical Report (`paper/technical_report.md`).
- `doctor.py` for environment health checks.
- GitHub Actions CI/CD pipeline.

### Changed
- Refactored code into modular structure (`src/`, `docs/`, `tests/`).
- Updated README with Live Demo badges and screenshots.

## [2.0.0] - 2026-10-16
### Added
- Multi-Agent orchestration (`nexus_agents.py`).
- RAG Service (`nexus_rag.py`).
- Pure-Python REST API (`api.py`).
- Model Cards documentation.

## [1.0.0] - 2026-10-15
### Added
- Initial release with 16 core analysis tools.
- Basic CLI interface.
- MIT License.
