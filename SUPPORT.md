# Support

Thank you for using NEXUS-RE! If you need help, here are the best ways to get it:

## Documentation
Before asking a question, please check our comprehensive documentation:
- [README.md](README.md) - Project overview and quick start
- [docs/](docs/) - Detailed architecture, CLI reference, and testing guides
- [Live Demo](https://qamar-sobhy-nexus-re-api.static.hf.space) - Try the platform in your browser

## Got a Question?
If you have a question about how to use NEXUS-RE, please:
1. Search existing [Issues](https://github.com/qamarsobhy7-source/nexus-re/issues) to see if it has already been answered.
2. If not, open a new issue using the **Bug Report** or **Feature Request** templates.

## Found a Bug?
Please open an issue using the Bug Report template. Include your OS, Python version, and steps to reproduce the issue.

## Security Vulnerabilities
**Do not open a public issue for security vulnerabilities.** Please refer to our [SECURITY.md](SECURITY.md) for responsible disclosure guidelines.

## Feature Requests
We welcome feature requests! Please open an issue using the Feature Request template and explain why the feature would be useful.
